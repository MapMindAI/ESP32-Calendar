# Rider–Waite–Smith tarot deck

This directory contains the 78 upright Rider–Waite–Smith (韦特) tarot card scans:

- `m00.jpg`–`m21.jpg`: Major Arcana, from The Fool through The World.
- `c01.jpg`–`c14.jpg`: Cups.
- `s01.jpg`–`s14.jpg`: Swords.
- `w01.jpg`–`w14.jpg`: Wands.
- `p01.jpg`–`p14.jpg`: Pentacles.

Each image is a 350 × 600 px JPEG. They were obtained from the
[metabismuth/tarot-json](https://github.com/metabismuth/tarot-json) dataset,
which identifies the Rider–Waite–Smith deck scans as public domain in the US.
The dataset code and metadata are MIT-licensed; see its upstream repository for
the full provenance and license terms.
